# Figure configs

These configs plot saved evaluation artifacts generated by this repository.
They never train a model or run evaluation. `${CADA_ROOT}` is the only
supported path placeholder; it is read from the `CADA_ROOT` environment
variable or `cada figure --root /absolute/path`.

## Included configs

`configs/figures/` contains four MS-4 examples:

- `kolmogorov__ms_4__h180__vorticity.yaml`: Kolmogorov vorticity snapshots
  spanning the 180-step rollout.
- `ks__ms_4__h640__spacetime.yaml`: KS spacetime spanning the 640-step rollout.
- `era5_small__ms_4__h60__temperature.yaml`: compact ERA5 500 hPa temperature.
- `era5_small__ms_4__h60__vorticity.yaml`: compact ERA5 500 hPa vorticity.

Each config records explicit trajectory, timestep, color, and layout choices.
The plots use the `truth`, `uncontrolled`, and `controlled` fields written by
CADA evaluation.

## Inputs

Figure inputs belong under `${CADA_ROOT}/publication/artifacts` and outputs
under `${CADA_ROOT}/publication/figures`. The artifact must be the strict
`.npz` or `.pt` evaluation artifact containing `truth`, `uncontrolled`,
`controlled`, and `metadata`.

Dry-run validates and resolves a config without requiring its input:

```bash
PYTHONPATH=src python -m cada figure \
  --config configs/figures/kolmogorov__ms_4__h180__vorticity.yaml \
  --dry-run
```
